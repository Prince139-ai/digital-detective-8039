### task 4.2 - compare compiler and interpreter

| point | compiler | interpreter |
| :--- | :--- | :--- |
| when translation / execution happens | translates whole program before running | translates and runs code line by line at runtime |
| typical output | executable binary file | direct execution in memory |
| one example | c or c++ | python or javascript |
| one advantage | runs faster | easier to test and find bugs |

explanation:
a compiler translates the entire source code into machine code before running and creates an executable file
an interpreter reads and executes the code line by line directly without making a separate file first
compiled programs run faster because the translation is already done
interpreted programs are slower but they make it easy to test changes quickly
