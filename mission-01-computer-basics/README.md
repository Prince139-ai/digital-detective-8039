## 4. my understanding

### task 1.1 - trace one activity using ipos
activity: typing and saving a document

| stage | what happens in your example | possible hardware / component |
| :--- | :--- | :--- |
| input | typing text using keyboard | keyboard |
| processing | cpu processes the letters and keeps them in ram | cpu and ram memory |
| output | letters appear on the screen | monitor |
| storage | file is saved to disk so it stays safe | ssd |

how activity moves:
user types letters on keyboard, cpu takes input and stores it in ram, monitor shows text on screen, user clicks save and cpu writes file from ram to ssd
